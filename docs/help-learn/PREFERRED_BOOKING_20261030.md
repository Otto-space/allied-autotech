# Preferred booking guidance checkpoint

Service-request article v4 describes the same service-page workflow: full mode can accept offered slots or a preferred Lagos time; limited modes retain enquiries. A request never confirms capacity. Quotation price remains unknown and no booking deposit is introduced. The article source/version participates in existing retrieval invalidation; no new guide target, permission or feature flag is introduced.

Implementation and tests remain on the development branch. No backend publication or production enablement. Anonymous sign-in draft recovery is bounded to 15 minutes in the same tab, with logout/external-account clearing and explicit re-review. Preferred-time rescheduling reuses the existing limit/cutoff and returns the booking to staff review. Concern-only requests, staff alternatives and complete acceptance remain outstanding in the delivery ledger.
