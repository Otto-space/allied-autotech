## Website Details

Build a Complete Website for Allied AutoTech

Create a modern, professional, premium and highly responsive website for Allied AutoTech, a modern automotive service and vehicle solutions company based in Port Harcourt, Nigeria.

## 1. Business Information

Business Name: Allied AutoTech
Location: 133 Stadium Road, beside Kilimanjaro, Port Harcourt, Rivers State, Nigeria
Phone/WhatsApp: 08136075567
Email: alliedautotech26@gmail.com
Social Media: @AlliedAutoTech on Instagram, TikTok and Facebook

Allied AutoTech provides professional automotive services, vehicle diagnostics, maintenance, tyre services, genuine automotive parts and vehicle sales.

The website should communicate trust, professionalism, technology, transparency and excellent customer service.

## 2. Main Website Goals

Build the website around these objectives:

1. Get customers to book automotive services online.
2. Allow customers to request quotations.
3. Showcase all automotive services.
4. Sell automotive products and genuine spare parts online.
5. Showcase vehicles available for sale.
6. Allow customers to contact customer care easily.
7. Generate leads through WhatsApp, phone calls and online forms.
8. Build trust through testimonials, reviews, completed projects and professional branding.
9. Make it extremely easy for a customer to find the workshop and contact Allied AutoTech.
10. Optimize the website for Google search so customers searching for automobile services in Port Harcourt can find Allied AutoTech.

Allow customers to optionally create accounts.

Customers should be able to:

- View their service bookings
- Track booking status
- View previous services
- View invoices
- View orders
- Track product orders
- Save vehicles
- Save favourite products
- Update their profile
- Contact customer care

Create a secure admin dashboard for Allied AutoTech staff.

The dashboard should allow administrators to:

- Manage customers
- Manage service bookings
- Manage products
- Manage product inventory
- Manage orders
- Manage vehicles for sale
- Manage enquiries
- Manage customer complaints
- Manage testimonials
- Manage promotions
- Upload images
- Update website content
- View sales

- View customer enquiries

Flash sale period: Say Mid November to Early December

- Revenue
- Most requested services

## 6. Payments

Design the system so it can support online payments in Nigeria.

Use a reliable Nigerian payment gateway such as Paystack or Flutterwave.

Customers should be able to:

- Pay for products
- Pay deposits for services
- Receive payment confirmation
- Receive order confirmation

Keep payment integration modular so the payment provider can be configured later.

## 7. WhatsApp Integration

Make WhatsApp a major part of the customer journey.

Add WhatsApp buttons throughout the website.

When a customer clicks WhatsApp from a product page, automatically generate a message such as:

"Hello Allied AutoTech, I am interested in [PRODUCT NAME]. Please provide more information."

For service bookings:

"Hello Allied AutoTech, I would like to book [SERVICE NAME] for my [VEHICLE]."

## 8. Design

The design should look like a premium modern automotive technology company, not a basic mechanic workshop website.

Use:

- High-quality automotive imagery
- Strong typography
- Modern cards
- Subtle animations
- Smooth scrolling
- Professional icons
- Large automotive imagery
- Clear call-to-action buttons

- iPhones

- Laptops
- Desktop computers

Hero → Services → Why Choose Us → Featured Products → Vehicles for Sale → Testimonials → Promotion → Location → Contact/WhatsApp

Make the primary actions highly visible:

BOOK A SERVICE | SHOP NOW | BUY A VEHICLE | WHATSAPP US

Build the website using a modern, scalable technology stack.

The application should have:

- Responsive frontend
- Secure backend
- Database
- Authentication
- Admin dashboard
- E-commerce functionality
- Booking system
- Payment integration capability
- WhatsApp integration

## 16. Important Requirement

Do not create only a visual mockup.

Build a functional website/application with working navigation, forms, booking functionality, product management, vehicle listings, customer enquiries and admin functionality.

Where external services such as payment gateways, Google Maps, WhatsApp or email require API keys, create clearly marked configuration fields/placeholders rather than hardcoding secret credentials.

Before completing the project, test:

- Mobile responsiveness
- Navigation
- Booking forms
- Product search
- Cart functionality
- Customer registration
- Admin login
- Admin dashboard
- WhatsApp links
- Contact forms
- SEO metadata
- Error handling

The final result should feel like a professional automotive technology and service platform for a growing Nigerian automotive company, with Allied AutoTech positioned as a trusted and modern automotive service brand in Port Harcourt.
