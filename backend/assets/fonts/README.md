# Document fonts

PDF documents embed the unmodified Quicksand Regular and Bold static fonts from the [Quicksand authors' repository](https://github.com/andrew-paglinawan/QuicksandFamily/tree/master/fonts/statics), retrieved 8 October 2026. The accompanying `Quicksand-OFL.txt` contains the license and copyright notice. No Nippo conversion or embedding is performed.

These runtime assets are included in the backend Docker image. Run the built backend alongside the `assets` directory as well as `dist` and installed production dependencies.
