## Contract

`GET /admin/service-categories/{categoryId}` now returns the existing administrator category projection independently of list position: ID, name, URL name, nullable description, active status, current version and timestamps. It includes inactive and empty categories. The route requires the existing Admin/Super Admin session and verified MFA, validates UUID/empty query input, returns 404 for missing categories, and sends `Cache-Control: private, no-store`. It includes no service records or new permissions.

The existing list still uses literal case-insensitive name-prefix search, active filtering, ascending name/ID order and signed filter-bound cursors. Public categories require an active category with an active service. Deactivation removes public grouping without unpublishing services or changing bookings. POST and PATCH retain CSRF, validation, audits and atomic expected-version enforcement.

The [category page](../../frontend/docs/page-quality/work-service-categories.md) uses direct reads for reloadable editing, pre-save revision reconciliation and explicit recovery after interrupted edits. A pre-save read does not prevent a subsequent concurrent update; PATCH retains its atomic revision check. Creation still has no durable original-request receipt: manual category-list reconciliation is required before explicitly starting a blank draft.
