# Allied AutoTech design system

The current brief supersedes earlier generated-image concepts. No AI-generated image is rendered. The original workshop asset remains on disk to preserve unrelated work. Genuine API media is displayed only from the approved host allowlist; missing or broken images use a neutral placeholder.

The existing navy/cobalt/white palette and Geist typography are retained as implementation assumptions, not a newly verified brand kit. No authorized Figma file or node reference was supplied or found. The connector account was accessible, but no file inspection or pixel-level Figma match is claimed.

## Tokens and composition

- Canvas: true white; surfaces: cool gray; primary text: deep near-black navy; action: cobalt blue; safety state: sparse orange.
- Type: Geist Sans for UI and Geist Mono only for identifiers, dates, and monetary detail.
- Shape: 2–12 px radii for normal controls, circular floating help buttons, restrained borders and shadows.
- Layout: 1120 px maximum content width, strong whitespace, thin borders, and a 4/8 px spacing rhythm.
- Imagery: approved backend product/vehicle photographs only. The homepage and authentication screens use typography and layout without invented workshop imagery.
- Icons: Lucide only, with visible text or accessible labels for unfamiliar actions.
- Copy: concise, concrete, and policy-accurate. Never claim a support response time or payment settlement before the API confirms it.
- Responsive behavior: desktop split-auth and dashboard rail collapse to a simple mobile header and single-column reading order.

## Interaction foundations

Persistent field labels, keyboard-visible focus, 44 px minimum primary controls, text status labels, native modal dialogs and persistent transaction feedback are used throughout. The automated help dialog restores focus to its trigger. Floating support controls use compact 48 px buttons; customer pages reserve bottom space. Tables have named, keyboard-focusable overflow regions.

Authenticated data belongs to the current session. Confirmed mutations refresh affected resources; failed refreshes retain useful prior data with an error. Money, stock, slots, payment and reservation outcomes are never optimistically confirmed. Creation and consequential changes have explicit review or recovery states.

## Content and evidence

Business identity and contacts come from the supplied brief. FAQ answers derive from those details and implemented application behavior. Social handles remain text until exact profiles are verified. Maps uses written address and address-based directions until an exact location can be verified. No fabricated hours, reviews, warranties, prices or guarantees are added.

The public [Link login](https://app.link.com/login) and [Termii sign-in](https://app.termii.ai/auth/signin) screens were successfully inspected in fresh anonymous Edge contexts after waiting for visible inputs. Link uses a compact centred form, generous whitespace and one primary continuation action. Termii uses a split brand/form composition, persistent labels, recovery access and a clear sign-in action. Allied AutoTech retains those useful principles in its compact form column, desktop brand panel and single-column mobile layout. No logos, imagery, wording, SLA figures or other business claims were copied. Screenshots are evidence in the local temporary directory, not application assets.
