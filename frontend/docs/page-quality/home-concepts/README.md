## Contract and brand corrections to the generated references

The owner's approved content, actual fonts, existing interactions and backend contract take precedence over illustrative output:

- Keep the repository wordmark, header navigation, shopping-bag control and original copy. Reject generated replacement logos, slogans, nationwide support, factory-training claims, sale/listing promises and additional badges.
- Keep the existing three horizontal partner links. Their explanatory copy and destinations are already approved; the concept's column arrangement is not required.
- Preserve all six actual journey steps and original principle text. The generated mobile board's abbreviated three-step story is not the production workflow.
- Use the original supplied technician poster. Generated technician portraits are not identity-preserving edits of that poster and are not substituted.
- Use API values only for catalogue titles, prices, currency, specifications, stock and reviews. The South African prices/locations and illustrated vehicle/product records in concepts are not production content. No featured or inspected badge is inferred.
- Keep the approved family/executive copy and inventory destinations. Lifestyle photographs remain explicitly editorial inspiration, separate from stock media.
- Keep complete vehicle photographs within reserved preview frames; varied source aspect ratios can produce letterboxing. Missing photographs receive a modest labelled fallback, never an unrelated stock photograph.
- At narrow widths, vehicle cards stack while product previews use compact horizontal rows. This preserves readable specifications and avoids oversized image placeholders.
- Native FAQ disclosure semantics remain, with a code-native chevron. Existing reduced-motion, carousel pause/keyboard/swipe and navigation behavior remain authoritative.
- The keyed Maps configuration is unrelated to Home. The address remains **133 Stadium Road, beside Kilimanjaro, Port Harcourt, Rivers State, Nigeria**.
