# Vehicle creation concept prompts

Mode: built-in Image Gen. The resulting desktop/mobile PNGs in this directory are
reference concepts, not application assets. The real Allied shell/logo and
supported field types replace generated approximations as specified in `spec.md`.

## Desktop prompt

Use-case ui-mockup. Create one high fidelity DESKTOP authenticated Allied AutoTech
workshop dashboard page at 1440px wide, full-page view of a professional vehicle
stock CREATION form. Existing-brand restrained automotive operational UI, cool
grey #f4f6f8 canvas, ink #01121a sidebar, red #e60301 primary action, white 12px
rounded form panels, Quicksand interface font, 13px readable labels, 28px heading,
44px controls. Preserve practical real-app shell: Allied logo text top-left,
narrow dark navigation sidebar with Overview, Service Centre, Shop, Vehicle
Marketplace expanded/Vehicle stock selected, Customers & Support, Finance, Team &
Access, Settings; top bar Find a page and account. Main breadcrumb Overview >
Vehicle stock > Add vehicle record. Heading Add vehicle record; subtitle 'Record
the vehicle first. Photos and sale listings follow.' Back to vehicle stock
secondary link. Main desktop form left ~760px and compact right guidance rail
~260px. Four neatly separated numbered form groups in order: 1 Vehicle identity
(Workshop branch dropdown Choose an active branch, Stock number, Make, Model,
Model year, Trim optional, Condition default Used); 2 Specifications (Mileage
optional km, Transmission optional, Fuel type optional, Body type optional, Drive
type optional, Engine size optional, Colour optional, Doors optional, Seats
optional); 3 Identifiers (VIN optional, Chassis number optional, Registration
number optional); 4 Acquisition (Acquisition cost optional NGN, Acquired at
optional Lagos time). All text fields blank, optional selects Not set. Two column
field grid, condition alongside trim, short helper 'Stock numbers are unique.
Required identity fields must be completed.' Guidance rail heading 'After you
save' with modest outlined CarFront/Image/Tag icon sequential three entries Save
stock record / Add photos and choose a primary image / Create a sale listing,
followed by subtle note 'Saving a stock record does not publish a sale listing.'
Footer red button Review new vehicle and neutral back link. No photograph, no
upload controls, no charts, no stock totals, no financial calculations. Plain
confident compact design matching actual operations, enough vertical space to
read all groups, no decorative large hero. This is a reference concept for code
implementation, keep text accurate.

## Mobile prompt

Use-case ui-mockup. One high fidelity MOBILE narrow 390px wide Allied AutoTech
authenticated workshop dashboard form, tall full-page screen scroll capture.
Professional restrained automotive operations, Quicksand readable 13px labels, ink
#01121a masthead with Allied branding and hamburger, cool #f4f6f8 canvas, compact
Find a page search/account bar, red #e60301 actions, white 12px panels, clear 44px
inputs. Breadcrumb Vehicle stock > Add vehicle record. Heading Add vehicle record
24px, short copy 'Record the vehicle first. Photos and sale listings follow.'
Back to vehicle stock link. A compact neutral After you save callout: Save stock
record > Add photos > Create a sale listing; explanatory text Saving does not
publish a listing. Form presents four numbered groups stacked in logical readable
order. 1 Vehicle identity: Workshop branch Choose an active branch, Stock number,
Make, Model, Model year, Trim optional, Condition Used. 2 Specifications: Mileage
optional km, Transmission Not set, Fuel type Not set, Body type Not set, Drive type
Not set, Engine size optional, Colour optional, Doors optional, Seats optional. 3
Identifiers: VIN optional, Chassis number optional, Registration number optional.
4 Acquisition: Acquisition cost optional NGN and Acquired at optional Lagos time.
Single-column fields, generous but compact label/input spacing, all blank values
except default Used and Not set dropdowns, no photos or upload buttons before a
record exists. Bottom red full-width Review new vehicle button and Back to vehicle
stock link. No invented counts, no charts, no sticky overlay obscuring fields, no
decorative hero. Preserve every field through this tall full-page layout. Make it
clear and clean and faithful to an administrative creation form.
