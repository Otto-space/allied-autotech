# Help Centre — concept references

Generated and inspected before implementation on 7 October 2026 for `/help`. Article detail pages remain a separate milestone.

1. [Search and topics](01-search-topics.webp): compact ink introduction/search, desktop topic rail and contiguous answer disclosures.
2. [Guidance and contact](02-guidance-contact.webp): lower answer states and one consolidated contact section.
3. [Mobile](03-mobile.webp): single-column layout, native topic selector, compact search and readable expanded answers.

The written brief controls the production scale and content: bundled Nippo/Quicksand, 36px maximum display heading, 44px minimum controls, existing header/footer and all twelve approved FAQ entries. Generated oversized lettering, altered logos and footer links are not adopted. Expanded answers illustrate interactive states; the initial list stays collapsed for scanning.

Search operates across the complete local article collection. Counts derive from that collection. Customer-specific actions require the appropriate account; work accounts receive only the existing support/security destinations that apply to them. No response times, opening hours, policy promises or company metrics are invented.

The [acceptance report](../help-expanded.md) records the final comparison, interaction checks and limitations.
