# Staff account detail — implementation specification

Use the real Allied dashboard shell and Quicksand. Background pale gray, restrained white sections and thin cool borders, red actions. Page heading30px desktop/24px mobile; section headings20px and body14px. Keep48px bordered controls,16px mobile input text and44px actions. No photos, charts, invented metrics or avatars for private account administration.

Hierarchy: route-aware named breadcrumb; Staff account with refresh; identity band with name, job title, email, role, account status and current branch; account facts and Manage access side-by-side at wide desktop; full-width responsibility and operational permission panels below. Mobile stacks identity, paired facts, access form, responsibility and capability panels. Account reference uses native disclosure. Preserve dates in Lagos time, inactive branch, unverified email, missing profile and self/protected explanations.

Account actions retain supported status/branch/demotion form and review modal. Super Admin responsibility panel uses compact summaries and disclosures for enrollment/position, assignment, revocation and eligible Admin delegation. Delegated Admin controls must follow verified server scope, not role alone. Operational permissions use ruled active rows, grant form, reasoned revoke and history disclosure. Permissions do not imply changes to role, branch, workforce assignment or refund separation requirements.

All changing actions must coordinate lock/review/confirmation and retain accurate receipts. Persist only minimal recovery metadata; require fresh authorized reads and independent reconciliation after ambiguous outcomes. No automatic replay, password storage, fake success or false audit guarantees. Disabled/error/loading states must prevent stale actions and display honest freshness. Keep drafts through ordinary refresh, retire only confirmed drafts, focus errors/review/success appropriately.

Acceptance requires native comparison at four baseline widths, responsive320–1920 checks, Axe, current-role/target authorization, status/branch/demotion, capability grant/revoke, enrollment/assignment/revoke/delegation, password visibility, dates/branch paging, stale/conflict/unknown/reload recovery, API/database preservation and connected actual workflow evidence. Detail is not complete until those checks pass. Existing unaffected fixtures/checks must not be repeated unnecessarily.
