# Vehicle detail concept brief

Mode: built-in Image Gen. Desktop and mobile concepts were generated and inspected
before implementation. These PNGs are reference concepts and are not application
photographs or UI assets. The following records the design brief; generated shell,
sample values and labels are reconciled against the actual application in the
specification and acceptance report.

Desktop: professional Allied AutoTech authenticated vehicle stock detail; dark ink
sidebar, cool grey canvas, white rounded panels, restrained brand red, Quicksand,
compact readable interface. Named 2022 Toyota Camry heading, stock/trim/workshop
context, breadcrumb, refresh/back controls and section navigation. Broad vehicle
facts beside narrower identity/acquisition facts. Complete sale listing card with
content, exact asking price, status, featured and publication information; edit,
price and status controls. Modest protected vehicle photos and existing management
actions. Private documents with assessment and temporary access. Latest condition
summary with score, odometer and typed findings. Avoid invented totals and charts.

Mobile: the same ordered sections in a readable narrow continuation. Actual
brand shell, named record, refresh/back, wrapping section links, complete facts
and identity, listing controls, photo management, private documents and condition
report. Preserve all facts and clear actions with usable control sizes. Internal
acquisition cost is administrator-only. Use the actual API versions, lifecycle
choices, document privacy and field labels when translating the generated concept.

Outputs: `desktop.png` (1024x1536) and `mobile.png` (838x1877). Generated mistakes
include a nonnumeric mobile version, approximate shell/logo, fabricated sample
photos/filenames and an Available-to-Available option; none establishes application
behavior. See `spec.md` for the implementation decisions made before UI edits.
