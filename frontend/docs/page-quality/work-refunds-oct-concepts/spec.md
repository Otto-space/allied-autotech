Allied logo, actual sidebar/navigation and account strip; do not adopt the generated
Admin User identity, red sidebar slab, rewritten mobile wordmark or decorative device

the generated mobile canvas has more room. Refresh records is secondary, not the

to NGN42,500 without evidence. Preserve all recorded times and full references rather

status badge in the same selected heading/value group. Back/close changes selection

concept canvas). Final comparison must use those actual dimensions and also inspect
