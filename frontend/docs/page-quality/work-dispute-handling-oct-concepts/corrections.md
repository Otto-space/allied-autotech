# Gate 86 concept corrections

Both fresh built-in ImageGen outputs were inspected at native resolution before implementation. Desktop is 1469 × 1071; portrait is 1024 × 1536. They establish hierarchy and surface treatment, not fabricated application data.

1. Keep the real Allied logo, navigation and global “Find a page” control. The generated dispute search, payouts/reconciliation navigation and extra sidebar routes are unsupported.
2. Use actual backend deadlines with Lagos formatting. The desktop January dates are incorrect for the synthetic October fixture. Never infer a deadline from a status.
3. Remove the invented numbered provider lifecycle; acknowledgement, evidence preservation, recorded submission and provider resolution are separate facts, not a fixed linear progression.
4. The portrait output is an overly wide layout compressed into a portrait canvas. Implement real 430px layout: rows wrap into labelled pairs, the overview link moves below the title, and assignment controls stack. Do not reproduce four tiny horizontal columns or two cramped mobile selectors.
5. Use real Quicksand and the compact established shell. No generated copy button, “internal note visible to your team” promise or 500-character counter: notes have the actual 10–2000-character contract and are not exposed as current note history.
6. Distinguish queue review from commit. Queue buttons are outlined; the explicit confirmation dialog sends the action. Selected state uses a thin red rule with a quiet tint; avoid repeated full red outlines and oversized pills.
7. Preserve all actual provider facts, assignments, evidence/checklist, precise lifecycle timestamps and safe identifiers in the selected workspace/disclosure. No generated omission is permission to discard operational information.
8. Use actual source record operator labels and eligible choices. Generated Ada/Emeka selections illustrate layout only; unassigned disputes start unassigned.
