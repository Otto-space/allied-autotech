# Services listing concept specification

Generated before implementation for `/services`. Original PNGs remain in the session's generated-image directory. These WebP copies are review references, never live page content or inventory.

- `01.webp`: compact introduction and service catalogue; open rows with fine dividers, visible pricing choices, real pricing or quotation labels, current-page count and pagination.
- `02.webp`: six-step journey and customer-care band. Existing approved journey copy is authoritative.
- `03.webp`: mobile adaptation, keyboard focus, loading, empty/error recovery and optional real image anatomy. The small journey/contact thumbnails are contextual only; image 02 defines those sections.

Tokens: white background, ink `#01121A`, red `#E60301`, readable red text `#BF0200`, muted text `#4F6073`, control border `#8290A1`, cool surface `#F3F5F8`. Nippo display headings, Quicksand body and UI; 44px controls, 4–6px corner radii, compact Lucide icons. Centered existing public container, desktop two-column introduction, divider-based catalogue rows, three-column journey at desktop and two/one columns on narrower screens.

Contract and existing-brand constraints take precedence over generated details: use the actual brand header/footer, existing decorative workshop image, and real API service records. Generated names/prices are concept examples only. No invented search, category taxonomy, global count or appointment availability. Keep the existing price formatter's kobo precision. The three-option filter uses a native radio fieldset for keyboard semantics. No drawer is needed for three choices. Do not reproduce generated logos, unapproved social links, or wording that diverges from the supplied service journey.
